  1. A point goes around.

    Nothing here is pre-rendered. Scroll back up and it runs in reverse, because every frame is a pure function of time.

  2. Its height is a wave.

    Each sample of the curve is computed for the time your scrollbar sets, then drawn as vector paths.

  3. Add circles and it sharpens.

    Each new circle is the next odd harmonic. The sum above is typeset with real TeX glyphs, and no LaTeX install is needed.

  4. Enough circles can draw anything.

    A discrete Fourier transform of one letter's outline, played as 121 turning circles.
