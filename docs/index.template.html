A few useful details

Before you build.

Do I need an AI agent?

You can write TSX yourself, adapt a component example, or work in the browser playground. An agent is another way to create the same editable source.

Where does rendering happen?

The playground renders locally in your browser. The CLI renders in Node.js on your machine or in CI. Browser editing supports PNG, SVG, and GIF animation preview and export. Use the CLI for larger scenes and automated rendering.

How do themes and backgrounds work?

Use semantic tones to render dark and light variants from one scene. PNG and SVG have alpha-transparent backgrounds by default. Add --background theme or background={c.bg} for an opaque canvas.

What happens when a scene grows?

Bare frames start at 960 × 540 and auto-grow to fit content. Set dimensions for fixed output, or use autoSize = false; when overflow should fail. Check the result and inspect it before sharing.
