A reliable workflow

Describe, check, render, inspect.

Start small. Keep the TSX as the source of truth, and use the CLI report before treating an export as finished.

01

Install the CLI

Vizmatic runs with Node.js 20 or newer. Install the renderer separately from any agent skill.

npm install -g vizmatic
02

Write one TSX frame

Use a bare frame for simple scenes. Start with Scene and a focused primitive, then add imports or a full module when the design needs them.

Choose a component →
03

Check both themes

Read the JSON diagnostics and fix errors before exporting. The check covers layout and readability.

vizmatic check ./frame.tsx --theme dark,light --json
04

Render and inspect

Render both variants, then inspect the actual files for clipping, spacing, and contrast.

vizmatic ./frame.tsx --out ./dist/frames --theme dark,light

For animation, use a module and the CLI.

Export createAnimation(theme) from a TypeScript module, keep create(theme) as its static fallback, then render with vizmatic gif ./animated-frame.tsx --out ./dist/frames --theme dark,light. A bare frame is for static output.

npx skills add bvolpato/vizmatic --skill vizmatic -g -y

The skill installer uses npm and requires Node.js. The Vizmatic renderer itself requires Node.js 20 or newer.

Questions

A few useful details.

Does installing the skill install Vizmatic?

No. The skill provides instructions and examples. Install the CLI with npm when the agent needs to check or render a frame.

Where does rendering happen?

The CLI renders on your machine or in your CI environment. Use the browser playground for interactive edits and previews.

How should I verify a finished visual?

Run the JSON check for dark and light themes, render both variants, and inspect the files at their final display size.
