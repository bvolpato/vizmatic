Render timing

One discarded warmup and three measured renders per example and theme. Each workload runs in a fresh Node process. Timing covers renderToPngWithOutput, including PNG encoding and file writing, after the example and renderer modules load. Median and nearest-rank p95 are shown; with three samples, p95 is the slowest sample. Output scale is 1.

Memory and quality

Peak RSS is Node's per-process process.resourceUsage().maxRSS, normalized to bytes and includes startup, imports, warmup, and measured renders. The quality counts come from vizmatic check examples --theme dark,light --json over all example files. They are automated diagnostics, not a human visual review.

Hardware, operating system, Node version, and source revision affect results. Compare runs on the same machine and runtime configuration. These measurements are informational, are not a CI performance threshold, and do not support claims about relative speed across different machines.
