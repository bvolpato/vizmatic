Vectype

Vector geometry for the stage engine. Every shape is a list of rings. A ring is a run of cubic Bezier segments in a flat array: [x0, y0, c1x, c1y, c2x, c2y, x1, y1, c1x, ...]. One representation for lines, arcs, glyphs, and imported SVG makes any shape morph into any other. Rings and paths are immutable by convention. Length tables and bounds are cached per ring, so sampling the same geometry on many frames stays cheap.
