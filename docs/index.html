The whole film is this much code.

A film is a plain function. Each s.play writes keys on a timeline, and the highlighted line is the one playing now.

import { axes, dot, draw, dynamic, fadeIn, film, line, morphMatching, tex, write } from 'vizmatic/stage'

export default film({ title: 'The derivative, in a page of code' }, (s) => {
    const graph = s.add(axes({ x: [-1, 3.5], y: [-1, 9], width: 1120, height: 780, grid: true }))
    graph.at(-300, 20)
    s.play(draw(graph.grid), draw(graph.lines), fadeIn(graph.numbers))

    const parabola = graph.plot((x) => x * x, { stroke: 'blue', width: 5 })
    s.play(draw(parabola))

    const h = s.value(1.8)
    const secant = dynamic(() => {
        const y = (x: number) => 1 + (2 + h.value) * (x - 1)
        const moving = 1 + h.value
        return [
            line(graph.world(0, y(0)), graph.world(3, y(3)), { stroke: 'yellow', width: 4 }),
            dot(9, 'teal').at(graph.world(1, 1)),
            dot(9, 'yellow').at(graph.world(moving, moving ** 2)),
        ]
    })
    s.play(fadeIn(secant))

    const ratio = s.add(tex('\\frac{(1+h)^2 - 1}{h}', { size: 72 }).at(590, -160))
    s.play(write(ratio))

    const result = tex('2 + h', { size: 88, color: 'yellow' }).at(590, -160)
    s.play(morphMatching(ratio, result))

    s.play(h.to(0.02, { duration: 3.5 }))
    s.wait(1.5)
})

What is different.

  • Every frame is a pure function of time.

    A film compiles to keys on tracks. Sampling any time needs no replay, so scrubbing runs both ways and a scroll bar can drive it.

    5.2 ms per seek

  • One source. Browser and MP4.

    The same function paints to a canvas and exports frame-exact H.264 on worker threads, about 60 frames per second at 1080p with bloom on 12 threads. On the same machine in the same run, the older layout-based video path reaches about 8 at 720p.

    60 fps export

  • Real math, with no LaTeX install.

    Equations are typeset with a bundled TeX engine into vector glyphs. Terms keep their identity, so equations morph term by term.

  • TypeScript, not Python.

    Films are typed modules that run on Node.js 20 or in a browser. Your editor knows every property.

  • Made for coding agents too.

    Plain functions, stable output, an installable skill, machine-readable docs, and a check command that reports problems as JSON.

  • Diagrams that hold a page of facts.

    93 typed components for architecture, data, and science, at print density by default and larger when you ask.
